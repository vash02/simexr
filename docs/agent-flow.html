🎯 Agent Responsibilities & Capabilities

🔄 Transform Agent

Data Flow:
  • Input: Raw GitHub scripts (any format)
  • Process: Parse, refactor, validate, optimize
  • Output: Standardized simulate() function
Key Operations:
  • Script import and parsing
  • Code structure analysis
  • Function standardization
  • Error detection and correction
  • Performance optimization

📊 Parameter Agent

Data Flow:
  • Input: Standardized script
  • Process: Extract, analyze, validate parameters
  • Output: Parameter schema and metadata
Key Operations:
  • Parameter discovery and extraction
  • Type inference and validation
  • Dependency mapping
  • Default value assignment
  • Constraint definition

⚡ Execution Engine

Data Flow:
  • Input: Script + validated parameters
  • Process: Safe execution with monitoring
  • Output: Simulation results and metrics
Key Operations:
  • Secure code execution
  • Resource management
  • Progress tracking
  • Error handling
  • Result collection

🧠 Reasoning Agent

Data Flow:
  • Input: Results + user questions
  • Process: AI analysis and reasoning
  • Output: Insights and visualizations
Key Operations:
  • Data pattern analysis
  • Scientific reasoning
  • Question interpretation
  • Visualization generation
  • Natural language responses
