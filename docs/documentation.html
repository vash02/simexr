🔄 End-to-End Workflow

sequenceDiagram participant User participant API participant Transform as Transform Agent participant Parameter as Parameter Agent participant Executor participant Reasoning as Reasoning Agent participant Database Note over User,Database: Phase 1: Model Import & Transformation User->>API: POST /simulation/transform/github API->>Transform: Import GitHub script Transform->>Transform: Refactor to simulate(**params) Transform->>Parameter: Extract parameters Parameter->>Parameter: Generate schema Parameter->>Database: Store model metadata API->>User: Model ready for use Note over User,Database: Phase 2: Simulation Execution User->>API: POST /simulation/run API->>Executor: Execute with parameters Executor->>Executor: Run simulation script Executor->>Database: Store results API->>User: Simulation complete Note over User,Database: Phase 3: AI Analysis User->>API: POST /reasoning/ask API->>Reasoning: Initialize with model_id Reasoning->>Database: Load simulation results Reasoning->>Reasoning: Analyze data & reason Reasoning->>Database: Store conversation API->>User: AI insights delivered

🚀 Quick Workflow Example

Step 1: Import Model from GitHub

curl -X POST "http://localhost:8000/simulation/transform/github" \ -H "Content-Type: application/json" \ -d '{ "github_url": "https://github.com/vash02/physics-systems-dataset/blob/main/vanderpol.py", "model_name": "vanderpol_demo", "max_smoke_iters": 3 }'

Result: Script automatically transformed into standardized simulate(**params) function

Step 2: Run Simulation

curl -X POST "http://localhost:8000/simulation/run" \ -H "Content-Type: application/json" \ -d '{ "model_id": "vanderpol_demo_abc123", "parameters": { "mu": 1.5, "z0": [2.0, 0.0], "eval_time": 20, "t_iteration": 1000 } }'

Result: Simulation executed with automatic result storage and validation

Step 3: AI Analysis

curl -X POST "http://localhost:8000/reasoning/ask" \ -H "Content-Type: application/json" \ -d '{ "model_id": "vanderpol_demo_abc123", "question": "How does the damping parameter mu affect oscillation behavior?", "max_steps": 10 }'

Result: Comprehensive AI analysis with scientific insights and visualizations

🔄 Transform Agent

  • Imports scripts from GitHub repositories
  • Converts code to standardized format
  • Validates script functionality
  • Handles error correction automatically

📊 Parameter Agent

  • Extracts simulation parameters
  • Tracks parameter relationships
  • Manages parameter validation
  • Organizes parameter metadata

🧠 Reasoning Agent

  • Analyzes simulation results
  • Answers scientific questions
  • Generates insights and patterns
  • Creates visualizations

⚡ Execution Engine

  • Runs simulations safely
  • Handles batch processing
  • Monitors execution progress
  • Manages resource allocation
